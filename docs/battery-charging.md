# Charging the KPL 4S LiPo Battery

This guide covers charging the **Keweenaw Propulsion Laboratory 4S 3300 mAh LiPo battery** using the Tenergy balance charger.

## Charger Settings

Configure the charger with the following settings:

| Setting        | Value                    |
| -------------- | ------------------------ |
| Battery Type   | **LiPo**                 |
| Charge Mode    | **Balance Charge (BAL)** |
| Cell Count     | **4S**                   |
| Charge Current | **3.0 A**                |

## Charging Procedure

1. Connect the charger to power.
2. Connect the battery's **main power connector**.
3. Connect the **balance connector**.
4. Select **LiPo Balance Charge**.
5. Set the charger to **4S** and **3.0 A**.
6. Press and hold **Enter/Start**.
7. Confirm the charger detects a **4S** battery.
8. Allow the battery to charge until the charger displays **FULL**.

## Stopping a Charge

To stop charging at any time:

1. Press and hold **Mode / Esc**.
2. Wait for the charger to return to the main menu.
3. Disconnect the battery.

## Discharging to Storage Voltage

LiPo batteries should **not** be stored fully charged for extended periods. If the battery will not be used within a day or two, use the charger's **LiPo Storage** mode to automatically charge or discharge the battery to the proper storage voltage.

### When to Use Storage Mode

Use **LiPo Storage**:

* Before storing the battery for more than a day or two.
* After a test or flight when the battery still has a high charge remaining.
* Before transporting or placing the battery into long-term storage.

### How to Use

1. Connect the battery's **main power** and **balance** connectors.
2. Select **LiPo Storage** on the charger.
3. Set the battery to **4S**.
4. Set the current to **3.0 A**.
5. Start the program and confirm the charger detects a **4S** battery.
6. Allow the charger to finish. It will automatically stop when the battery reaches the proper storage voltage.

The charger will either:

* **Charge** the battery if it is below storage voltage, or
* **Discharge** the battery if it is above storage voltage.

For a 4S battery, the storage voltage is approximately **15.3 V (3.8 V per cell)**.

> **Note:** The charger can only dissipate a limited amount of power when discharging, so reducing a fully charged battery to storage voltage may take considerably longer than charging. Patience is normal during this process.



## Safety

* Never leave the battery charging unattended.
* Always use **Balance Charge** or **LiPo Storage** mode.
* Do not charge a battery that is swollen, damaged, or hot.
* Stop charging immediately if the battery becomes hot, swells, or the charger reports an error.
